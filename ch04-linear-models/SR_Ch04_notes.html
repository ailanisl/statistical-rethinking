Ch 4: Geocentric Models

Ch 4: Geocentric Models Notes

Ptolemy is often ridiculed for his geocentric model of the solar system, but he was mathematically brilliant. He computed an accurate model of the motions of the planets (epicycles - accurate from the earthly perspective, would just have to be re-calibrated every 100 years). Makes useful predictions given narrow domain of questioning. = Generalized system of approximation (Fourier series).

Linear regression is the geometric model of applied statistics. Linear regression: family of simple golems attempting to learn about the mean and variance of some measurement using an additive combinations of other measurements

Linear regression as a Bayesian procedure

Which uses a Gaussian (normal) distribution to describe our golem’s uncertainty about some measurement of interest.

Binomial distribution models the number of discrete successes (k) in a fixed number (n) of independent binary trials (Y/N, T/F). As the number of trials becomes large, the binomial distribution approaches the continuous Gaussian distribution, which is characterized by a bell-shaped curve defined by its mean and SD.

Normal by addition

Random walks on a soccer field.

pos <- replicate(1000,sum(runif(16,-1,1)))
plot(density(pos))

INC number of steps INC stabilization on the Gaussian distribution. Any process that adds together random values from the same distribution converges to normal. Fluctuations from the mean cancel themselves out - most likely sum is sum in which every fluctuation is canceled by another (sum of zero)

  • Regardless of underlying distribution

Normal by multiplication

Another way to get normal distribution.

prod(1+runif(12,0,0.1))
[1] 1.929559
  • Samples 12 random numbers between 1.0 and 1.1, each representing a proportional increase in growth. The product of all 12 is computed and returned.
growth <- replicate(1e4, prod(1 + runif(12,0,0.1)))
dens(growth, norm.comp=TRUE)

The effect at each locus was multiplied by the effects at all the others, NOT ADDED. Normal distribution because the effect at each locus is SMALL (multiplying small numbers is approx same as addition).

Note

Small effects that multiply together are approximately additive, so they tend to stabilize on Gaussian distributions

big <- replicate(1e4, prod(1+runif(12,0,0.5)))
small <- replicate(1e4, prod(1 + runif(12,0,0.01)))
dens(big, norm.comp=TRUE)
dens(small, norm.comp=TRUE)

Normal by log-multiplication

log.big <- replicate(1e4, log(prod(1+runif(12,0,0.5))))
dens(log.big, norm.comp=TRUE)

Adding logs is equivalent to multiplying the original numbers. Measurement scales are arbitrary, and it’s natural to measure sound, earthquakes, information on a log scale.

Using Gaussian distributions

Ontological reason: World full of Gaussian distributions: measurement errors, variations in growth, velocities of molecules.
Processes that add together fluctuations.

  • Member of exponential family of natural distributions

Epistemological reason: Maximum entropy → minimal assumptions about the data (just that the measure has finite variance)

curve( exp( -x^2 ) , from=-3 , to=3 )

Gaussian is continuous - value \(y\) can be any continuous value. In contrast to binomial, which requires integers.

  • Probability mass functions: discrete outcomes (like binomial) → denoted \(Pr\)

    • Cannot be greater than 1

  • Probability density functions: continuous outcomes → denoted \(P\) or \(f\) .

    • can be greater than 1

      • Probability density is the rate of change in cumulative probability

      • Area under the density function will never exceed 1 = probability mass

A language for describing models

TipRecipe for statistical models
  1. Recognize set of variables we want to understand. Data are observable variables. Parameters are unobservable, like rates and averages.
  2. For each variable, define it either in terms of other variables or a probability distribution
  3. Combination of variables and their probability distributions defines a joint generative model that can be used both to simulate hypothetical observations as well as analyze real ones.
NoteSummarizing the model

\(y_{i}\) ~ \(Normal(µ_{i}, σ)\)

\(µ{i} = 𝛽x{i}\)

\(𝛽\) ~ \(Normal(0,10)\)

\(σ\) ~ \(Exponential(1)\)

\(x_{i}\) ~ \(Normal(0,1)\)

Revising the globe-tossing model:

\[W \sim {\sf Binom}(N, p)\]

\[p \sim {\sf Uniform}(0,1)\]

  • Likelihood function used in Bayes’ thm: The count \(W\) is distributed binomially with sample size N and probability \(p\)

  • Define priors: The prior for \(p\) is assumed to be uniform between 0 and 1

Stochastic: indicated by ~ symbol. No single instance of the variable on left is known with certainty, but is instead characterized by a probabilistic mapping

w <- 6; n <- 9;
p_grid <- seq(0,1,length.out=100)
posterior <- dbinom(w,n,p_grid) * dunif(p_grid,0,1)
posterior <- posterior/sum(posterior)

Working with columns

  • $ → extract the column named height from the data frame d
d$height
d2 <- d[d$age >= 18,]
  • Index notation: [row, column]
dens(d2$height)
  • Height raw data looks approx Gaussian, BUT not a good idea to gawk at raw data and decide how to model them

Write general model and compute plausibility of each µ and σ. To define the heights as normally distributed with a mean µ and sd σ:

\[h_{i} \sim {Normal}(µ,σ) \]

  • h → list of heights

  • subscript i –> each individual element of list, takes on row numbers (1-32, no. heights in d2$height )

All the golem knows about each height measurement is defined by the name normal distribution with mean µ and standard dev σ. The model assumes that the values \(h_{i}\) are independent and identically distributed (IDD). In other words, each value of h has the same probability function, independent of the other h values and using the same parameters. But hardly true - heights within families are correlated.

Priors

The parameters to be estimated are µ and σ → so need prior \(Pr(µ, σ)\) or the joint prior probability for all parameters. Assume that they’re independent of each other or \(Pr(µ, σ) = Pr(µ)Pr(σ)\)

\[h_{i} \sim {Normal}(µ,σ) \]

\[µ \sim{Normal}(178, 20)\]

\[σ \sim {Uniform}(0, 50)\]

The prior for µ is a broad Gaussian prior, centered on 178cm, with 95% of probability between 178 ±40.

  • Why 178 cm? Author is 178 cm tall. And the range from 138 cm to 218 cm encompasses a huge range of plausible mean heights for human populations. So domain-specific information has gone into this prior. Everyone knows something about human height and can set a reasonable and vague prior of this kind.

Whatever the prior, it’s a very good idea to plot your priors, so you have a sense of the assumption they build into the model.

curve(dnorm(x,178,20), from=100, to=250, xlab = "mu",ylab="density")
  • the golem is assuming that the average height (not each individual height) is almost certainly between 140 cm and 220 cm.

The σ prior is a truly flat prior, a uniform one, that functions just to constrain σ to have positive probability between zero and 50cm. View it with:

curve(dunif(x,0,50), from=-10, to=60)

Prior predictive simulation

  • See what your priors imply about the distribution of heights

  • Helps diagnose bad choices

  • Simulate heights by sampling from the prior

sample_mu <- rnorm(1e4, 178,20)
sample_sigma <- runif(1e4,0,50)
prior_h <- rnorm(1e4, sample_mu, sample_sigma)
dens(prior_h, xlab="height")

  • Expected distribution of heights, averaged over the prior

  • Prior prob distribution is not itself Gaussian - not an empirical expectation but a distribution of relative plausibilities of different heights, BEFORE seeing the data

Compare to a less informative prior for average height µ ~ Normal(178,100). Priors with large SDs are common in Bayesian models, but not really sensible.

sample_mu <- rnorm(1e4, 178,100)

Sampling from the posterior

To summarize and understand the posterior distribution, like in Ch3. New thing: since 2 parameters and need to sample combos of them, we first randomly samples row numbers in post in proportion to values in post$prob. Then pull out parameter values on those randomly sampled rows.

sample.rows <- sample(1:nrow(post), size=1e4, replace=TRUE, prob=post$prob)
sample.mu <- post$mu[sample.rows]
sample.sigma <- post$sigma[sample.rows]

plot(sample.mu, sample.sigma, cex=0.5, pch=16, col=col.alpha(rangi2,0.1))

Since these samples are just vectors of numbers, you can compute any statistic from them that you could from ordinary data.

Sample size and the normality of the standard dev’s posterior: Posterior is not always so Gaussian in shape. For a Gaussian likelihood and a Gaussian prior on µ, the posterior distribution is always Gaussian as well, regardless of sample size. It is the standard deviation σ that causes problems. So if you care about σ—often people do not—you do need to be careful of abusing the quadratic approximation.

Posterior of σ has long right-hand tail. Variances (SDs) must be positive (more uncertainty about how big it is rather than how small it is.

Finding posterior distribution with quap

Quadratic approximation: quickly make inferences about the shape of the posterior. The posterior’s peak → maximum a posteriori estimate (MAP) = useful image of posterior’s shape at this peak

quap in rethinking - define the posterior probability at each combination of parameter values.

  • Then climbs the posterior distribution and find the peak, its MAP.

  • Estimates the quadratic curvature at the MAP to produce an approximation of the posterior distribution.

  • Remember: This procedure is very similar to what many non-Bayesian procedures do, just without any priors.

library(rethinking) # repeat code to load data and select out adults
data(Howell1)
d <- Howell1
d2 <- d[ d$age >= 18 , ]
Model definition R code
\(h_{i} \sim {Normal}(µ,σ)\) height ~ dnorm(mu, sigma)
\(µ \sim{Normal}(178, 20)\) mu ~ dnorm(178,20)
\(σ \sim {Uniform}(0, 50)\) sigma ~ dunif(0,50) 
flist <- alist(
  height ~ dnorm(mu, sigma),
  mu ~ dnorm(178, 20),
  sigma ~ dunif(0,50)
)

Fit model to the dataframe d2:

# fit model stored in m4.1
m4.1 <- quap(flist, data=d2)

These numbers provide Gaussian approximations for each parameter’s marginal distribution. This means the plausibility of each value of µ, after averaging over the plausibilities of each value of σ, is given by a Gaussian distribution with mean 154.6 and standard deviation 0.4.

Start values for quap climbing a hill - needs to start at some combo of parameter values (usually random vals sampled from prior). Possible to specify starting val, like the mean and sd in this context.

Linear Prediction

Predictor variable: independent variable we posit predicts the outcome if it has statistical association with the outcome variable.

How Kalahari height (outcome var) covaries with weight (predictor var). Seems dull now because readers don’t have a theory about growth and life history in mind.

Plot the height and weight against one another to get a sense of how they covary:

plot(d2$height, d2$weight)

How to incorporate predictor vars into Gaussian model?

The linear model strategy. Make the parameter for the mean of a Gaussian distribution µ ito a linear function of the predictor variable and other new parameters we invent.

  • This instructs the golem to assume that the predictor variable has a constant and additive relationship to the mean of the outcome. It then computes the posterior distribution of this constant relationship

We ask the golem: “Consider all the lines that relate one variable to the other. Rank all of these lines by plausibility, given these data.”

The golem answers with a posterior distribution.

Case study: one predictor variable (weight). How to get weight into Gaussian model of height? Define µ as a function of values in x (d2$weight), with \(\overline{x}\) as the average of weights.

\(h_{i} \sim {Normal}(µ_{i},σ)\) likelihood height ~ dnorm(mu,sigma)
\(µ_{i} = \alpha + \beta(x_{i} - \overline x)\) linear model mu ← a + b*weight
\(\alpha \sim{Normal}(178, 20)\) \(\alpha\) prior a ~ dnorm(178, 20)
\(\beta \sim{Normal}(0,10)\) \(\beta\) prior b ~ dlnorm(0,1)
\(σ \sim {Uniform}(0, 50)\) \(\sigma\) prior sigma ~ dunif(0,50)

Probability of the data

Probability of the observed height. The mean µ noe depends on unique values on each row i.

Linear Model

The mean µ is not longer a parameter to be estimated, instead \(µ_{i}\) is determined by other parameters \(\alpha\), \(\beta\), and the observed variable \(x\). We know \(µ_{i}\) with certainty (not stochastic). \(x_{i}\) is weight value on row \(i\).

Asks two questions:

  1. What is the expected height when \(x_{i} = \overline{x}\) ? \(µ_{i} = \alpha\) when \(x_{i} = \overline{x}\).
  2. What is the change in expected height when \(x_{i}\) changes by 1 unit? \(\beta\) is the slope - rate of change in expectation

Find the line that relates \(x\) to \(h\) - a line that passes through \(\alpha\) when \(x_{i} = \overline{x}\) and has slope \(\beta\)

Remaining priors

These last priors define distributions for the unobserved variables.

\(\beta\) prior: why Gaussian prior with mean 0?

  • Know that height INC with avg weight. Restrict to positive values → define prior as \(\beta \sim{Log-Normal}(0,1)\). Log of \(\beta\) has a Normal(0,1) distribution

Important to fuss over priors (even if they end up being irrelevant due to big data). Because some priors may end up being relevant for many other analyses and it helps us build better models.

NoteChoosing priors

Priors encode states of info before seeing the data.

  • In cases with good prior info that discounts the plausibility of some parameter values (e.g., neg associations between height and weight) - encode directly in priors

  • Vary priors and repeat the analysis in order to study how different states of initial info influence inference

  • Often, many reasonable priors produce same inference

  • Conventional Bayesian priors are conservative relative to conventional non-Bayesian approaches

  • Choose priors conditional on pre-data knowledge of the data (constraints, ranges, theoretical relationships) never conditional on the observed sample

Finding the posterior distribution

Just incorporate new model of the mean into the model specification inside quap and make sure to add a prior for the new parameter \(\beta\)

#load data again, since it's a long way back 
library(rethinking)
data("Howell1")
d <- Howell1
d2 <- d[d$age >= 18,]

# define the average weight, x-bar 
xbar <- mean(d2$weight)

#fit model 
m4.3 <- quap(
  alist(
    height ~ dnorm(mu, sigma),
    mu <- a + b*(weight - xbar),
    a ~ dnorm(178,20),
    b ~ dlnorm(0,1),
    sigma ~ dunif(0,50)
  ),
  data=d2)

TipRecipe for generating predictions and intervals from the posterior of a fit model
  1. Use link to generate distributions of posterior values for µ. The default behavior of link is to use the original data, so you have to pass it a list of new horiz axis values you want to plot posterior predictions across
  2. Use summary functions like mean or PI to find averages and lower and upper bounds of µ for each value of the predictor variable
  3. Finally, use plotting functions like lines or shade to draw the lines and intervals. Or you might plot the distributions of the predictions, or do further numerical calculations with them

Recipe words for every model we fit in the book. As long as you know how parameters relate to the data, you can use samples from the posterior to describe any aspect of the model’s behavior.

Briefly, B-splines divide the full range of some predictor variable (e.g., year) into parts. Then they assign a parameter to each part. These parameters are gradually turned on and off in a way that makes their sum into a fancy, wiggly curve.

  • Generate new predictor variables and use those in the linear model, \(µ_{i}\)

  • Invent series of new, synthetic predictor variables (basis functions), each of which serves to gradually turn a specific parameter on and off within a specific range of the predictor variables

  • Now the linear model:

\[ µ_{i} = \alpha + w_{1}B_{i,1} + w_{2}B_{i,2} + w_{3}B_{i,3} + ...\]

  • where \(B_{i,n}\) is the n-th basis function’s value on row \(i\) and the \(w\) parameters are corresponding weights for each. parameters act as slopes, adjusting the influence of each \(B\) on the mean \(µ_{i}\)

How do B-splines work?

Simple case: Approximate temp data with 4 different linear approximations

  • Divide the full range of x-axis into N parts, using pivot points called knots.

  • At each knot, one basis function has value 1, the rest are set to 0.

  • At any point on the x-axis, only 2 basis functions have non-zero values, so the parameters for those two basis functions are the only parameters influencing the prediction at a given x-point (year).

    • Compared to polynomial regression, in which parameters influence the entire shape of the curve

  • Each basis function is multiplied by its corresponding (positive or negative) weight parameter, which are derived from fitting the model to the data

  • To improve the simple case:

    • Use more knots

    • Use higher degree polynomials instead of linear approx

Second, choose your polynomial degree. This determines how basis functions combine, which determines how the parameters interact to produce the spline.

  • Deg 1 → 2 basis functions combine

  • Deg 2 → 3 basis functions combine

  • Deg 3 → 4 basis functions combine

R has built in splines library with function bs() to construct basis functions for any list of knots, degree.

        knots=knot_list[-c(1,num_knots)],
        degree=3, intercept=TRUE)

for (i in 1:ncol(B)) lines(d2$year, B[,i])

Third, define the model and make it run to get the parameter weights for each basis function. Each column of matrix B as variable. Get intercept to capture the average temp - priors on base weights will be deviation from the intercept.

\[T_{i} \sim Normal(µ_{i}, σ)\]

\[µ_{i} = \alpha + \sum_{k=1}^{K}{w_{k}B_{k,i}}\]

As for the priors:

\[\alpha \sim {\sf Normal}(6,10)\]

  • Intercept: The mean of 6 deg Celsius is the historical average March temp in Kyoto. The SD of 10 is weakly informative - allows the intercept to span roughly -14C to 26C

\[w_{j} \sim {\sf Normal}(0,1)\]

  • Spline weights: Mean = 0: no knot region is expected to deviate from the intercept (baseline temp) by default. SD of 1 is regularizing, no crazy wiggles - spline can shift µi by roughly +/-1 C at any knot region

\[sigma \sim {\sf Exponential}(1)\]

  • SD: The residual year-to-year temperature variability around the spline trend. Exponential suports only positive reals = \(\sigma\) > 0. Encodes weakly informative belief that sigma is probably not enormous, with a soft tail. Rate =1 means the prior mean is 1 - gentle regularizer that nudges sigma away from 0 and from large values

quap and matrix multiplication. Make sure to use a start list for the weights to tell quap how many there are.

  • B %*% w is shorthand for (1) multiplying each element of the vector w by each value in the corresponding column of B and then (2) summing up each row of the result.
m4.7 <- quap(
  alist(
    T ~ dnorm(mu, sigma),
    mu <- a + B %*% w,
    a ~ dnorm(6,10),
    w ~ dnorm(0,1),
    sigma ~ dexp(1)
  ),
  data=list(T=d2$temp, B=B),
  start=list(w=rep(0,ncol(B)))
)
