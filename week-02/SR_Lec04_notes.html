1) Question/Goal/Estimand

How are height, weight, and sex causally related?
How are height, weight, and sex statistically weighted?

2) Scientific model

The causes aren’t in the data

  • H → W: the arrow does from height to weight because there are fewer interventions on height than on weight (you can change your diet, exercise, etc. to change your weight, but not height). Height necessarily influences weight.

  • S → H: human biology, height does not influence sex; but sex does

  • S → H: same as above

  • Weight is influenced by both height (directly) and sex (both directly and indirectly via H)

Translate DAGs into generative models by turning them into functions

\[ H = f_{H}(S) \]

\[ W = f_{W}(H,S) \]

Indirect causes do not show up in generative functions
Unobserved causes are ignorable unless shared among generative causes (H, W, S)

Synthetic people

# S=1 female; S=2 male 
sim_HW <- function(S,b,a){
  N <- length(S)
  H <- ifelse(S==1, 150, 160) + rnorm(N, 0, 5) # add Gaussian noise with variance of 25cm
  W <- a[S] + b[S]*H + rnorm(N,0,5) 
  data.frame(S,H,W)
}

S <- rbern(100) + 1 # 100 individuals with male and female drawn at random 
dat <- sim_HW(S, b=c(0.5, 0.6), a=c(0,0)) 
# both alphas are zero - no sex effect on intercept
# slightly diff slopes: 0.5 for women, 0.6 for men

3) Statistical model(s)

ImportantCoding categorical variables
  1. Indicator (0/1) variables
  2. Index variables: 1,2,3,4
    1. One of the sexes becomes the default, while the other becomes the adjustment

  • We will use index variables

    • Extend to many categories with no change in code

    • Better for specifying priors

    • Extend effortlessly to multilevel models

Vector of parameters, with index

\[ \alpha_{S[i]} \]

\[ \alpha = [\alpha_{1}, \alpha_{2}] \]

Statistical Model

\[ W_{i} \sim {\sf Normal}(µ_{i}, \sigma) \]

\[ µ_{i} = \alpha_{s[i]} \]

Priors

\[ \alpha_{i} \sim {\sf Normal}(60,10) \]

\[ \sigma \sim {\sf Uniform}(0,10) \]

S <- rbern(100)+1
dat <- sim_HW(S,b=c(0.5,0.6), a=c(0,0))

# Estimate posterior 
m_SW <- quap(
  alist(
    W ~ dnorm(mu, sigma),
    mu <- a[S],
    a[S] ~ dnorm(60,10),
    sigma ~ dunif(0,10)
  ), data=dat
)
