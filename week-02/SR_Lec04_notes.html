1) Question/Goal/Estimand

How are height, weight, and sex causally related?
How are height, weight, and sex statistically weighted?

2) Scientific model

The causes aren’t in the data

  • H → W: the arrow does from height to weight because there are fewer interventions on height than on weight (you can change your diet, exercise, etc. to change your weight, but not height). Height necessarily influences weight.

  • S → H: human biology, height does not influence sex; but sex does

  • S → H: same as above

  • Weight is influenced by both height (directly) and sex (both directly and indirectly via H)

Translate DAGs into generative models by turning them into functions

\[ H = f_{H}(S) \]

\[ W = f_{W}(H,S) \]

Indirect causes do not show up in generative functions
Unobserved causes are ignorable unless shared among generative causes (H, W, S)

Synthetic people

# S=1 female; S=2 male 
sim_HW <- function(S,b,a){
  N <- length(S)
  H <- ifelse(S==1, 150, 160) + rnorm(N, 0, 5) # add Gaussian noise with variance of 25cm
  W <- a[S] + b[S]*H + rnorm(N,0,5) 
  data.frame(S,H,W)
}

S <- rbern(100) + 1 # 100 individuals with male and female drawn at random 
dat <- sim_HW(S, b=c(0.5, 0.6), a=c(0,0)) 
# both alphas are zero - no sex effect on intercept
# slightly diff slopes: 0.5 for women, 0.6 for men

NoteCoding categorical variables

  2. Index variables: 1,2,3,4

Vector of parameters, with index

\[ \alpha_{S[i]} \]

\[ \alpha = [\alpha_{1}, \alpha_{2}] \]

Statistical Model

\[ W_{i} \sim {\sf Normal}(µ_{i}, \sigma) \]

\[ µ_{i} = \alpha_{s[i]} \]

Priors

\[ \alpha_{i} \sim {\sf Normal}(60,10) \]

\[ \sigma \sim {\sf Uniform}(0,10) \]

Post processing

  • The unknowns themselves, a[1] and a[2], are not what we want; we have to do comparisons between these posterior distributions

  • The diff of mean weight is not in the posterior, the mean weight of each category is. But we’d like to look at the contrast between category 1 and 2

  • Need to use whole posterior distribution

NoteAlways be contrasting

  • Contrast is often what we want, the difference between categories

  • It’s never legitimate to compare overlap in distributions - in parameters or lines

    • This means no comparing confidence intervals or p-values either

Index Variables and Lines

  • Ignore sex for a moment, regression on weight from height

\[ W_{i} \sim {\sf Normal}(µ_{i}, \sigma) \]

\[ µ_{i} = \alpha + \beta(H_{i} - \overline{H}) \]

  • Centering H makes it so that alpha is the average weight of a person with average height.

  • Centering makes it easier to define scientific priors for alpha

    • alpha = expected weight at the expected height

      • so when \(H_{i} = \overline{H}\) → \(\beta\) * 0 → beta/slope has no effect

Now let’s add sex

\[ µ_{i} = \alpha_{S[i]} + \beta_{s[i]}(H_{i} - \overline{H}) \]

  • \(S[i]\) sex of i-th person (1=female, 2=male)

\[ \alpha = [\alpha_{1}, \alpha_{2}], \beta = [\beta_{1},\beta_{2}] \]

  • Two intercepts and two slopes, one for each value in S

Analyze the Sample

data("Howell1")
d <- Howell1
d <- d[d$age >= 18,]
dat <- list(
  W = d$weight,
  H = d$height,
  Hbar = mean(d$height),
  S = d$male + 1) 

m_SHW <- quap(
  alist(
    W ~ dnorm(mu, sigma),
    mu <- a[S] + b[S]*(H-Hbar),
    a[S] ~ dnorm(60,10),
    b[S] ~ dunif(0,1),
    sigma ~ dunif(0,10)
  ), data=dat, 
  start = list(
    a = c(60, 60),
    b = c(0.4, 0.4),
    sigma = 6)
)

  • Gravity’s around 0, not much difference at any height between men and women’s heights

    • Taller women tend to weigh more than men of the same height

    • Shorter men tend to weigh more than women of same height

  • Nearly all of the causal effect of sex on weight acts thru height

NoteSummary: Category variables

  • Easy to use with index coding

  • Use samples to compute relevant contrasts

  • Always summarize (mean, intervals) as the last step

    • Do not summarize first and then take a difference

  • Want mean difference and NOT difference of means
